CONCEPT
What is Euclid's Division Lemma?
Quick Recall 🧠 — A lemma is a mathematical statement that has already been proven. It is used as a stepping stone to prove bigger theorems. Euclid was a Greek mathematician who laid the foundation of modern number theory.
a = b × q + r
where   0 ≤ r < b
a = Dividend b = Divisor q = Quotient r = Remainder
Key Condition: The remainder r is always non-negative and always less than the divisor b. That is, 0 ≤ r < b. Also, the quotient q and remainder r are always unique — there is only one possible pair (q, r) for any given a and b.

In everyday language:

Dividend = (Divisor × Quotient) + Remainder
This is exactly what happens when you do long division! Euclid just gave it a formal mathematical statement.
📐 Worked Examples
23 = (2 × 11) + 1
a = 23  |  b = 2
q = 11  |  r = 1
Check: 0 ≤ 1 < 2 ✓
54 = (7 × 7) + 5
a = 54  |  b = 7
q = 7  |  r = 5
Check: 0 ≤ 5 < 7 ✓
63 = (9 × 7) + 0
a = 63  |  b = 9
q = 7  |  r = 0
Check: 0 ≤ 0 < 9 ✓
9 divides 63 exactly!
100 = (13 × 7) + 9
a = 100  |  b = 13
q = 7  |  r = 9
Check: 0 ≤ 9 < 13 ✓
🔢 Application: Odd & Even Integers

Let a be any positive integer and b = 2. By Euclid's Division Lemma:
a = 2q + r, where r can only be 0 or 1 (since 0 ≤ r < 2).

When r = 0 → EVEN

a = 2q + 0 = 2q
Any multiple of 2 is even.

q=1 → 2 q=2 → 4 q=3 → 6 q=4 → 8

When r = 1 → ODD

a = 2q + 1
One more than a multiple of 2.

q=1 → 3 q=2 → 5 q=3 → 7 q=4 → 9
Conclusion: Every positive integer is either of the form 2q (even) or 2q + 1 (odd), where q is a non-negative integer. This is directly derived from Euclid's Division Lemma!
🔁 Finding HCF — The Big Application CBSE IMPORTANT

Euclid's Division Lemma is the foundation of the Euclid's Division Algorithm — a powerful method to find the HCF of large numbers.

1
For two positive integers c > d, write: c = d × q + r
Apply Euclid's Lemma: find q and r such that 0 ≤ r < d.
2
If r = 0, then d is the HCF. Done!
If r ≠ 0, replace: now apply lemma to d and r.
3
Keep repeating until the remainder becomes 0.
The last non-zero divisor is the HCF!

Example: HCF of 420 and 130

420 = 130 × 3 + 30
130 = 30 × 4 + 10
30 = 10 × 3 + 0   ← remainder = 0, STOP
∴ HCF(420, 130) = 10 ✅

BOSS QUESTION 01 · PROOF TYPE · 50 XP
Using Euclid's Division Lemma, show that the square of any positive integer is either of the form 3m or 3m + 1 for some integer m, but never of the form 3m + 2.
✅ Model Solution

Let n be any positive integer. By Euclid's Lemma with b = 3, n can be written as:

n = 3q, or n = 3q + 1, or n = 3q + 2

Case 1: n = 3q
n² = 9q² = 3(3q²) = 3m where m = 3q²

Case 2: n = 3q + 1
n² = 9q² + 6q + 1 = 3(3q² + 2q) + 1 = 3m + 1 where m = 3q² + 2q

Case 3: n = 3q + 2
n² = 9q² + 12q + 4 = 9q² + 12q + 3 + 1 = 3(3q² + 4q + 1) + 1 = 3m + 1

In all three cases, n² is either 3m or 3m + 1. It is never of the form 3m + 2. Hence proved. ✅
BOSS QUESTION 02 · PROOF TYPE · 50 XP
Show that any positive odd integer is of the form 4q + 1 or 4q + 3 for some non-negative integer q.
✅ Model Solution

Let n be any positive integer. By Euclid's Lemma with b = 4:

n = 4q + r, where 0 ≤ r < 4

So r can be 0, 1, 2, or 3, giving us four cases:


n = 4q → Even (divisible by 4)
n = 4q + 1 → Odd ✓
n = 4q + 2 = 2(2q+1) → Even
n = 4q + 3 → Odd ✓

Since 4q and 4q + 2 are both even, every positive odd integer must be of the form 4q + 1 or 4q + 3. Hence proved. ✅
BOSS QUESTION 03 · APPLY · 60 XP
Use Euclid's Division Lemma to prove that one and only one out of n, n+2, and n+4 is divisible by 3. (Where n is any positive integer.)
✅ Model Solution

By Euclid's Lemma with b = 3, any positive integer n is of the form 3q, 3q+1, or 3q+2.


Case 1: n = 3q
n = 3q → divisible by 3 ✓
n+2 = 3q+2 → not divisible by 3
n+4 = 3q+4 = 3(q+1)+1 → not divisible by 3

Case 2: n = 3q+1
n = 3q+1 → not divisible by 3
n+2 = 3q+3 = 3(q+1) → divisible by 3 ✓
n+4 = 3q+5 = 3(q+1)+2 → not divisible by 3

Case 3: n = 3q+2
n = 3q+2 → not divisible by 3
n+2 = 3q+4 = 3(q+1)+1 → not divisible by 3
n+4 = 3q+6 = 3(q+2) → divisible by 3 ✓

In every case, exactly one of n, n+2, n+4 is divisible by 3. Hence proved. ✅
BOSS QUESTION 04 · MCQ · 40 XP
What are the possible remainders when the cube of any positive integer is divided by 9?
✅ Explanation
Any integer n = 3k, 3k+1, or 3k+2.
(3k)³ = 27k³ = 9(3k³) → remainder 0
(3k+1)³ = 9[k(3k²+3k+1)] + 1 → remainder 1
(3k+2)³ = 9[k(3k²+6k+4)] + 8 → remainder 8
So possible remainders are 0, 1, and 8.
